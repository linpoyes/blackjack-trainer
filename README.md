## 規則設定

8 副牌 · 莊家軟 17 停牌（S17）· 分牌後可加倍（DAS）· A 分牌各補一張 · 最多 4 手 · 不可投降 · BJ 賠 3:2
→ 理論莊家優勢 **≈ 0.43%**

換規則答案會變。桌上若標示 *Dealer hits soft 17* 或 *Blackjack pays 6:5*，策略表與優勢都要重算。

## 四個分頁

- **查表檢討** — 自己點出莊家明牌與手牌（最多 6 張）復盤賭場遇到的牌。可作答（計分）或直接看最佳打法（不計分）。牌超過兩張時「加倍」自動關閉。
- **實戰模擬** — 真發牌真結算，含分牌至 4 手、加倍、A 分牌只補一張、莊家 peek、切牌 72% 重洗。一手結束後列出每個打錯的決定與思考秒數。
- **策略表** — 硬牌 / 軟牌 / 對牌三張表，虛線框是你做錯過的格子；下方失誤排行可跳「錯題重練」。
- **練習記錄** — 每日 100 手目標條、14 天長條圖、判斷錯誤回顧（可展開看當時牌面並載回查表檢討）。

鍵盤 `H` `S` `D` `P` 直接作答，`空白鍵` 下一手。

## 帳號與練習記錄

第一次打開會要求輸入**暱稱**與**四位數字密碼**，那就是你的帳號 —— 不需要 Email、不需要 Google 登入。

換手機、換瀏覽器、重灌，打同一組暱稱＋密碼就會把記錄讀回來。暱稱被別人用過而密碼不對會被擋下。
密碼在試算表裡只存 SHA-256 雜湊，看不到原始四位數。

每一次判斷會寫進 Google 試算表：

- **帳號** — 暱稱 / 密碼雜湊 / 建立時間 / 最後使用
- **手牌記錄** — 時間 / 日期 / 練習者 / 來源 / 手牌 / 莊家明牌 / 你選 / 正解 / 對錯 / 秒數
- **每日統計** — 日期 × 練習者 的手數 / 正確 / 正確率（增量更新，不重算全表）

寫入節流 15 秒一批、離線先存本機（最多 800 筆）、回到網路自動補傳，所以不會拖慢作答。
頁尾可以「切換帳號」。

技術上：寫入走 POST（`no-cors`，不需要讀回應）；讀取走 **JSONP**，因為 Apps Script 的 `/exec`
跨網域無法用一般 fetch 讀回應。

> 四位數密碼只是朋友之間分辨記錄用的，不是資安機制。別拿它保護任何重要的東西。

## 這份與原始 artifact 的差異

以 claude.ai 對話裡的原始 artifact 為基準，修掉在瀏覽器環境會出事的地方：

| 問題 | 處理 |
|---|---|
| `window.storage`（Artifact 專用 API）在瀏覽器不存在，且被 `try/catch` 吞掉 → **重整頁面記錄全失** | 改用 `localStorage` |
| Google Fonts 三個外部請求，render-blocking | 改系統字型，整份零外部請求 |
| 每次重繪都重跑發牌動畫（分牌後最明顯） | 移除動畫 |
| 每張牌 `0 6px 16px` 陰影 + 牌桌 60px inset shadow | 大幅減輕 |
| 暫停用 `filter:saturate+brightness` 蓋住整塊，牌看不清、繼續鍵在桌外 | 改桌內橫幅，牌看得見，繼續鍵就在旁邊 |
| 每次點擊建 ripple DOM + `setTimeout` | 移除 |
| 隱藏的策略表 / 練習記錄分頁每手都重建整張表 | 只在該分頁可見時才重繪 |
| 計時器 100ms | 250ms |

## 部署

前端推 `main` 即自動上線（GitHub Pages，legacy build，約 20 秒）。

後端改 `gas/Code.gs` 後需重新部署版本；`setup()` 放在檔案最前面，因為 Apps Script 編輯器預設選第一個函式，第一個函式必須無參數且可安全執行。

## 現實提醒

完美基本策略下莊家優勢仍約 0.43%，長期期望值為負。這個工具練的是「不要多輸」，不是「保證會贏」。

- 賭場若只賠 **6:5**，莊家優勢惡化約 **1.4%**，任何打法都補不回來 —— 這種桌直接不要坐
- 連續洗牌機（CSM）讓算牌完全失效
- 賭場是私人場所，有權拒絕服務
