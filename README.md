# 戰勝21點 · Blackjack Trainer

單檔離線網頁，直接用瀏覽器開 `index.html` 就能用。無後端、無外部資源、無網路請求。
所有紀錄存在瀏覽器 localStorage（key: `zhansheng21_v1`），不會上傳。

## 規則設定

| 項目 | 設定 |
|---|---|
| 牌副數 | 8 |
| 莊家軟 17 | 停牌（S17） |
| 分牌後加倍 | 允許（DAS） |
| A 分牌 | 各補一張，不可再分 |
| 分牌上限 | 4 手 |
| 投降 | 不可 |
| Blackjack | 賠 3:2 |

**換規則答案會變。** 例如莊家軟17補牌（H17），11 對 A 就變成加倍、軟19 對 6 也變加倍。

## 四個分頁

### 策略表
硬牌 / 軟牌 / 對子三張完整表格，**由策略引擎即時生成**——表格和實際判定用的是同一份程式碼，不可能不一致。
- 點任一格看那格的理由
- 白框格 = 你曾經答錯過的位置
- 下方「失誤排行」是累計統計（看長期趨勢），可一鍵跳到「錯題重練」

### 查表檢討
- 上排選莊家明牌，下排點出你手上的牌（最多 6 張）
- 「退回一張」「清空」，輸錯不用重來
- 兩種用法：按 H/S/D/P 自己作答（計分、記進每日手數），或按「直接看最佳打法」（不計分，純查表）
- **牌超過兩張時「可加倍」自動關閉並鎖住** — 真桌上補過牌就不能再加倍
- 只有兩張牌時也可以手動關掉「可加倍」，模擬分牌後不能加倍的桌
- 下方檢討清單：作答錯的標「錯」，查詢的標「查」，各附正解，最多留 30 筆

### 實戰模擬
真的發牌、真的結算，包含分牌（至 4 手）、加倍、A 分牌只補一張、莊家 peek、切牌到 75% 重洗。
- 指標列：淨額 / 手數 / 正確率 / SHOE 剩餘 / **THINK**（本次決定秒數）/ **TIME**（本場總時長）
- **暫停**：牌桌變暗、按鍵鎖住，秒數與總時長都不累加，按「繼續」接回原本的讀秒
- 打錯不會被強制修正——照你的選擇走，讓你看到後果
- 「重新開始」重洗牌盒並歸零淨額與計時

### 練習記錄
- 今日 / 累計手數與正確率、最近 14 天每日紀錄
- **判斷錯誤回顧**：按時間倒序，按日期分組（今天標「今天」），最多 80 筆
  - 標籤顯示來源：`查表` 或 `模擬`
  - 附當時的思考秒數 — 看得出是不知道還是想太久
  - **點一下展開**：看當時的實際牌面（不只是「硬 16」，而是 10+6 還是 10+4+2）、完整理由、當時是否不能加倍
  - 「載入到查表檢討」一鍵把那手牌填回去重新作答

三處分工不重複：
- 策略表「失誤排行」→ 哪些格子錯最多次（累計，看趨勢）
- 練習記錄「判斷錯誤回顧」→ 每一次錯的時間順序（看今天錯在哪）
- 查表檢討清單 → 你主動查過的牌組（賭場回來復盤用）

建議流程：翻錯誤回顧 → 記下重複出現的牌型 → 「錯題重練」打 20 手。

## 驗證

策略引擎對照權威基本策略表（8 副 / S17 / DAS / 不可投降）逐格比對：

```
340/340 cells correct, 0 failures     # 硬牌16列 + 軟牌8列 + 對子10列 × 10 欄莊家明牌
fallback OK (5/5)                     # 不能加倍時的替代動作
莊家優勢 = 0.424%                      # 3,000,000 手蒙地卡羅（教科書值 0.43%）
```

## 現實提醒

完美基本策略下莊家優勢仍約 **0.43%**，長期期望值為負。這個工具練的是「不要多輸」，不是「保證會贏」。

- 賭場若只賠 **6:5**，莊家優勢直接惡化約 **1.4%** — 任何打法都補不回來，這種桌直接不要坐
- 連續洗牌機（CSM）讓算牌完全失效
- 澳門桌多為 8 副牌，穿透率通常不佳
- 賭場是私人場所，有權拒絕服務
